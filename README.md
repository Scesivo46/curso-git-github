# Curso de Git, GitHub y GitLab desde cero

Curso básico e interactivo para principiantes, en español.

**👉 Ver el curso:** https://scesivo46.github.io/curso-git-github/

## Contenido
- 11 módulos: de qué es Git hasta colaborar con pull/merge requests
- Instrucciones para **GitHub** y **GitLab** en cada paso (con selector de plataforma)
- Simulador de Git interactivo con misiones
- Cuestionarios, chuleta de comandos y glosario
- Proyecto final: publicar tu propia web con GitHub Pages o GitLab Pages
- Adaptado a móvil y con modo claro/oscuro

Es un único archivo `index.html`, sin dependencias: también funciona sin conexión.
